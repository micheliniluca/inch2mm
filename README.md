# Calcolatrice ft·in·mm

Calcolatrice per lunghezze, aree e volumi in piedi-pollici con frazioni e in millimetri.
Pagina statica: nessun server, nessun dato inviato. Storico e preferenze restano nel browser di chi la usa.

## Pubblicazione su GitHub Pages
1. Crea un repository (es. `calcolatrice-ftin-mm`) e carica tutti i file di questa cartella nella radice.
2. Settings → Pages → Source: *Deploy from a branch* → Branch `main`, cartella `/ (root)` → Save.
3. Dopo un minuto la trovi su `https://<utente>.github.io/calcolatrice-ftin-mm/`.

## Installarla come app
- Edge/Chrome su PC: icona "Installa" nella barra degli indirizzi (o Menu → App → Installa).
- Telefono: "Aggiungi a schermata Home".
Una volta aperta, funziona anche offline.
